MERN Stack

Finoire Architecture Overview

Finoire is a full-stack personal finance and expense analytics web application. Built with React (Vite) on the frontend and Node.js / Express on the backend, with MongoDB for document storage.

Key Technical Features

  • Tokenized authentication using JSON Web Tokens (JWT) & HTTP-only cookies
  • Interactive financial metrics powered by Recharts (Income vs Expense vs Savings)
  • Budget warning threshold indicators with automated status badges
  • Express RESTful API with mongoose data models and input validation

PHP & MySQL

Quizara Architecture Overview

Quizara is an online examination and learning management system built using server-side Native PHP (PDO) and relational MySQL database engines.

Key Technical Features

  • Relational MySQL schema with foreign keys connecting exams, attempts, and users
  • Automated printable PDF certificate generation using FPDF library for score > 75%
  • Time-limited password recovery emails sent via PHPMailer SMTP integration
  • Interactive student dashboard displaying XP accumulation, quiz attempts & rankings

TechNest Architecture Overview

TechNest is a full-featured e-commerce platform built for buying and selling high-end tech gadgets. Features a modern glassmorphism storefront and a comprehensive admin management panel.
